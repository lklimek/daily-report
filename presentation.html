Your Wallet, Your Way

Who benefits: End users running Dash Evo Tool

  • Multiple wallets just work — If your Core node has several wallets loaded, DET now auto-detects which one to use. No more cryptic "Wallet file not specified" errors. If detection is ambiguous, a clean dialog asks you once — your choice is remembered. #695
  • Your secrets stay secret — Passwords and private keys are masked by default with a hold-to-reveal eye icon. Behind the scenes, sensitive data is zeroed from memory when no longer needed and locked against swap. #709
  • Errors you can actually understand — "Duplicate key" tells you the key is already registered. "Connection timed out — trying another server" replaces the useless "Could not connect to the Dash network." Errors now guide you, not confuse you. #739 #731 #744 #751

A Network That Heals Itself

Who benefits: Anyone using the SDK — app developers, DET users, WASM/browser apps

  • Dead nodes are gone before you notice — The SDK probes all DAPI nodes at startup and bans broken ones immediately. Your first request already hits a healthy node. #3353
  • Broken nodes don't come back too soon — When a ban expires, the node is re-probed before being allowed back. Still dead? Ban escalates. No more hitting the same broken node twice. #3353
  • Works everywhere — Health checks run in native Rust apps AND in the browser via WASM. Same reliability for JS and web developers. #3353
  • Your funds are protected — Fee validation now prevents accidentally burning funds on unshield and withdrawal operations (1000× upper-bound guard). #3223

Real-Time Platform, No More Polling

Who benefits: App developers building on Dash Platform

  • Subscribe to live events — New gRPC streaming API delivers block commits and state transition results in real-time. Build responsive dashboards, instant confirmation UIs, and event-driven integrations — no polling required. #2795
  • Query token distributions — New getTokenPreProgrammedDistributions endpoint lets apps display scheduled token distribution data with full proof verification. #3246
  • Your identity addresses are monitored — SPV wallets now automatically watch identity authentication addresses (DIP-9). UTXOs at these addresses are no longer invisible — transactions show up without manual setup. #668

Quality You Can Trust

Who benefits: Everyone — fewer bugs, faster releases, better reviews

  • Automated PR reviews — AI-powered code review catches issues before humans even look. Deployed across both DET and Platform repos. #712 #764 #3347
  • End-to-end testing — New headless test harness validates wallet creation, identity registration, DPNS, and withdrawals automatically — no GUI needed. #673 #701
  • Faster CI — Path-filtered workflows skip irrelevant tests. gRPC cache no longer triggers unnecessary rebuilds. Weekly build health checks alert on Slack before breakage reaches users. #3219 #3193
